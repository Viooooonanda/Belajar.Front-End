Pengertian HTML

HyperText Markup Language

HTML adalah bahasa yang digunakan untuk membuat struktur dasar halaman web.

Fungsi HTML: digunakan untuk membuat struktur dasar dan konten suatu halaman web (seperti teks, gambar, tautan)

Pengertian CSS

Cascading Style Sheets

CSS adalah bahasa stylesheet yang digunakan untuk mengatur tampilan, tata letak, warna, font, dan desain visual dari sebuah halaman website yang dibuat dengan HTML
